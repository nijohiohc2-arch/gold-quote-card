## 2. 결과 요약
- **아이디어/니치**: 카톡·전화로 금 매입 문의를 받는 1~4인 금은방. 매장명·시각·유효시간·단가가 찍힌 "확정 매입 견적 카드"를 폰으로 30초 안에 발행해 방문으로 연결합니다. 근거: 2026년 금 매도 문의 급증 보도, 카톡 사전 견적 실측 후기(확정 견적을 준 매장이 판매 성사), 시계·귀금속 사업체 8,706개(국세청, 2026.3).
- **테스트베드**: 주 채널은 금은방 사장님 1:1 채널(기존 거래처 카톡 + 인스타 금은방 계정 DM). 보조로 네이버 카페 "아프니까 사장이다"(노출)와 크몽 단건 상품(결제 검증). 14일 계획, 성공 기준(응답률 ≥20%, 사용 ≥5곳, 신청 ≥3건, 결제 ≥1건), 게시 문구 5종, 채널별 `?ref=` 추적 링크를 준비했습니다.
- **프로토타입**: vanilla JS 단일 페이지(백엔드·유료 API 없음, localStorage). Netlify 배포 후 HTTP 200 확인.
- **테스트**: 라이브 대상 Playwright 38/38 PASS(데스크톱 1280 + 모바일 390, 콘솔 에러 0). 라이브 1차 실행에서 Netlify 배지가 탭을 가리는 결함(B1)을 발견해 고친 뒤 재검증했습니다. **실사용자 시장 테스트는 미실시**(외부 게시 금지 조건). 최 앨런 님이 게시하면 시작합니다.

## 4. 미결 사항 · 가정 · 리스크
1. **시장 테스트 미실시**: 게시·연락 금지 조건 때문입니다. 테스트베드.md 6장 문구로 최 앨런 님이 직접 실행해야 합니다. 지불 의향·전환율 데이터는 아직 없습니다.
2. **가격(39,000~69,000원 / 월 9,900원)은 가설**입니다. 근거 데이터가 없습니다.
3. **Netlify 무료 플랜 배지**가 우하단에 표시됩니다. 레이아웃으로 피했지만, 없애려면 플랜이나 설정을 확인해야 합니다(에이전트가 확인하지 못함).
4. **실기기 미검증**: iOS Safari, 카카오톡 인앱 브라우저에서의 이미지 공유(Web Share)와 클립보드. 첫 사용 매장과 함께 확인하길 권합니다.
5. **데이터가 기기에만 저장**됩니다(기기를 바꾸거나 브라우저 데이터를 지우면 사라짐). 백업 기능으로 보완했습니다.
6. 기본 적용률(22K/18K/14K 95%)과 예시 시세(690,000원)는 **예시값**입니다. 매장마다 설정해야 합니다.
7. "아프니까 사장이다" 회원 수(약 190만 명 이상)는 검색 요약 값이라 직접 확인이 필요합니다. 금은방 사장님 전용 커뮤니티는 검색 범위 안에서 찾지 못했습니다(없다고 단정하지는 않음).
8. **GitHub 업로드 방식**: 저장소 생성, 업로드 검증(트리·파일 조회), 완료보고서 최종 갱신 커밋은 GitHub MCP로 했습니다. 소스·문서·PNG 스크린샷 원본 업로드는 박스에 이미 로그인된 같은 계정(`gh`, nijohiohc2-arch)으로 `git push`했습니다. GitHub MCP의 파일 업로드는 내용을 텍스트로 직접 넣어야 해서, PNG 같은 바이너리를 올릴 수 없고 약 100KB 분량의 코드를 다시 입력하면 원본과 달라질 위험이 있기 때문입니다.
9. 처음에 Netlify MCP 파라미터 스키마를 확인하려고 빈 요청을 보냈을 때 임시 이름(lively-mochi-78cd72)으로 프로젝트가 생성되었습니다. 이 프로젝트를 `geumgyeonjeok`으로 이름을 바꿔 그대로 사용했으므로 중복 프로젝트는 없습니다.
